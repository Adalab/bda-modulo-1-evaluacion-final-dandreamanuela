# 1. Ejercicio de gestión de inventario de una tienda

# 2. Descripción
El programa permite gestionar un inventario de productos.
El usuario puede revisar el inventario, actualizar cantidades, eliminar productos, calcular el valor total del inventario y realizar compras.

# 3. Tecnologías
• Python.
• Jupyter Notebook.
• ChatGPT y Claude.


# 4. Estructura del proyecto
• El ejercicio se compone de un único archivo Jupyter Notebook nombrado "evaluación_módulo 1_DA" y este ReadMe de acompañamiento.

# 5. Cómo ejecutar el proyecto
• El proyecto sigue las instrucciones indicadas en el archivo "evaluacion-final-pt.pdf".
• Una vez abierto el Jupyter Notebook en Visual Code, ejecutar los ejercicios 2.1-2.7. de manera consecutiva.

# 6. Funcionalidades
• El programa permite:
- agregar un producto al inventario o actualizar su cantidad si ya existe.
- mostrar el inventario de cada producto con sus detalles.
- buscar un producto en el inventario por nombre, mostrar sus detalles si se encuentra o indicar que no se ha encontrado si no está.
- actualizar el stock de un producto en el inventario o indicar que no se ha encontrado si no está.
- eliminar un producto del inventario o indicar que no se ha encontrado si no está.
- calcular y mostrar el valor total del inventario.
- a un cliente realizar una compra seleccionando productos del inventario calculando el valor total de la compra y actualizando el inventario.
